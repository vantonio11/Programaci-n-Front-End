PROMPT 2 — FORMULARIOS Y VALIDACIONES
-------------------------------------------------------
En index.html integra/verifica 3 formularios con labels vinculados (for/id):

1. Registro (#registerForm) — nombre, email, contraseña, confirmar contraseña
2. Login (#loginForm) — email, contraseña
3. Contacto (sección nueva #contacto) — nombre, email, mensaje (<textarea>)

Cada <label> debe tener for="id" apuntando a su <input> correspondiente.

Validaciones JS (sin librerías) en cada submit:
- Campos vacíos → mostrar error inline bajo el input
- Email: regex /^[^\s@]+@[^\s@]+\.[^\s@]+$/
- Contraseña: mín 8 chars, al menos 1 número y 1 mayúscula
- Confirmar contraseña: debe coincidir
- Mensaje: mínimo 10 caracteres
- Sanitizar inputs: trim() y escapar < > antes de procesar
- No exponer mensajes de error que revelen si el email existe

Reutiliza clases CSS existentes: .form-group, .auth-msg, .btn-primary,
variables --cyan, --navy2. Los JS de validación ya existen en
./js/Formulario de Login.js y ./js/Formulario de Registro.js — extiéndelos.

PROMPT 3 — ESTRUCTURAS DE DATOS Y FUNCIONES MODULARES
-------------------------------------------------------
Refactoriza el JS de index.html y los archivos ./js/ aplicando:

ESTRUCTURAS DE DATOS:
- Objeto usuario: { id, nombre, email, password, fechaRegistro, rol:'user' }
- Arreglo global: const usuarios = [] — almacena inscritos al registrarse
- Objeto sesion: { activo: false, usuario: null } — estado del login

FUNCIONES MODULARES (nombrar exactamente así):
- validarDatos(formData)     → retorna { valid, errores[] }
- registrarUsuario(datos)    → crea objeto usuario, push a usuarios[]
- iniciarSesion(email, pass) → busca en usuarios[], actualiza sesion
- cerrarSesion()             → resetea sesion
- cambiarImagen(direccion)   → lógica del carrusel (+1/-1 en índice)
- actualizarDOM(seccion)     → re-renderiza productos, carrusel o resumen
- mostrarError(inputId, msg) → inyecta error inline bajo el input
- limpiarErrores(formId)     → elimina todos los errores del form

REGLAS:
- Ninguna lógica dentro de onclick="" en HTML, solo llamadas a funciones
- Los archivos ./js/Formulario de Login.js y Registro.js deben exportar
  sus funciones al scope global (window.validarDatos = validarDatos)
- Usar const/let, arrow functions, sin var
